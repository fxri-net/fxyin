# 修复 PHP 8.5 废弃调用与静态门禁

## 背景

- PHP 8.5 起 `curl_close()` 废弃：句柄自 8.0 起是对象，离开作用域自动释放，该调用已无作用。

1. 删除 `Curl::request()` 中的 `curl_close()` 调用，并就地注释不调用的原因。
2. 新增 `phpstan-deprecation.neon`：引入 `phpstan/phpstan-deprecation-rules`，`phpVersion` 取 CI 矩阵上限 `80500`，路径 `src`。

4. 引入开发依赖 `phpstan/phpstan-deprecation-rules`（仓库不提交 `composer.lock`，CI 自行解析）。
5. 复查全仓是否还有同类废弃调用（`_close`/`_free`/`imagedestroy`/`utf8_encode`/`strftime` 等）。

`src/Http/HttpClient/Curl.php`、`phpstan-deprecation.neon`（新增）、`composer.json`、`.gitattributes`；不改运行时行为，资源与对等矩阵不动。

## 验证方式

1. 用 `phpVersion: 80500` 跑一次门禁，确认能报出 `Call to deprecated function curl_close()`（修复前已验证报错）。

3. `pnpm verify` 全绿。

## 完成情况

## 背景
