# 补齐时间分解与标识串格式

延续「补齐语言前后缀与首字母大写」（见 active/202610/20261028-唐启云-补齐语言前后缀与首字母大写.md）。复核 `Text` 后发现两处能力只有子集实现。

计划位置：本轮第 2 项；前置：补齐语言前后缀与首字母大写。

## 背景

- `Text::timeFormat($time, $param)` 把秒数按 `switch/title/format/show/zero/max/before` 分解为「1年2月3天」；v2 `Time::relative()` 只输出固定文案「3小时前」。
- `Text::timeMilli($mtime)` 支持三种形态：13 位毫秒转 `Y-m-d H:i:s.mmm`、`Y-m-d H:i:s.mmm` 转毫秒、空值取当前毫秒；v2 `Time::milli()` 只处理整型。
- `Text::uuid($mode, $param)` 在给定 UUID 时可直接格式化或大写现有串；v2 `Uuid::make()` 给种子时一律 MD5 派生，无法只做格式归一。

## 实施方案

1. `Time::decompose(int $seconds)` 返回年/月/天/时/分/秒的分解结果，单位链与 v1 一致（30 天/月、12 月/年）。
2. `Time::duration(int $seconds, array $labels = [], bool $zero = false, ?string $max = null, bool $before = true)` 按标签拼接；标签留空即关闭该单位，对应 v1 的 `switch/show/title`，`max` / `before` / `zero` 语义对齐。
3. `Time::milliFormat(int $milliseconds)` 输出 `Y-m-d H:i:s.mmm`；`Time::milliParse(int|string $value)` 接受 13 位毫秒串与带毫秒的时间串，非法输入抛 `InvalidArgumentException`。
4. `Uuid::format(string $value, ?UuidStyle $style = null)` 把现有标识串去横线、转大写并按 8-4-4-4-12 重新分段，对应 v1 模式 1/2 的「格式化现有 UUID」。
5. 补测试：时长分解与标签配置、毫秒双向转换、现有标识串格式化。
6. 更新对等快照与 `docs/text.md`、`docs/support.md`。

## 影响范围

`src/Text/Time.php`、`src/Text/Uuid.php`、对应测试、`docs/text.md`、`tests/Parity/legacy-api.json`；既有 `relative()`、`milli()`、`make()` 签名与行为不变。
