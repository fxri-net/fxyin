# 发布 2.1.0

对等计划第 8 项；前置：能力矩阵、资源与语言、配置、应用层、能力补齐、路由、对等测试全部完成。

## 背景

对等能力作为 `2.1.0` 特性版本发布；默认加载内置资源属于行为变化，需要单列说明。

## 实施方案

1. 确认对等测试与矩阵全绿。
2. 建 `minor` 变更集，说明内置语言/配置默认加载、应用层、能力补齐与行为变化。
3. 消费变更集，`Package::VERSION` 与 `package.json` 对齐 `2.1.0`。
4. 更新日志、文档站同步、`pnpm verify`。
5. 发布前向用户确认；确认后打附注标签并推送三远程。

## 影响范围

`package.json`、`CHANGELOG.md`、`docs/changelog.md`、`src/Package.php`、变更集；不改运行时语义之外的行为。

## 验证方式

1. `pnpm verify` 全绿。
2. 发布包含 `resources` 且无开发文件。
3. Packagist 可解析 `2.1.0`，三远程标签一致。

## 回滚方案

标签未推送可删除；版本与日志可 `git revert`。
