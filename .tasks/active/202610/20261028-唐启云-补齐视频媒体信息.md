# 补齐视频媒体信息

延续「补齐时间分解与标识串格式」（见 active/202610/20261028-唐启云-补齐时间分解与标识串格式.md）。复核 `File` 后发现 `getMediaInfo` 没有对应能力。

计划位置：本轮第 3 项；前置：补齐时间分解与标识串格式。

## 背景

- v1 `File::getMediaInfo($var, 'video')` 执行配置中的 ffmpeg 命令，解析输出得到时长、秒数、码率、视频编码、封装、分辨率、宽高、音频编码、采样率、文件大小与 `play_time`。
- v2 `File\MediaInfo` 只做 MIME 与扩展名互查，与视频元信息不是同一能力。

## 实施方案

1. 新增 `File\VideoInfo`：`inspect(string $file, array|string $command)` 执行探测命令并解析输出。
2. 命令支持 `[二进制, ...参数]` 数组形式（不经 shell）与 `%s` 占位模板字符串（文件路径经 `escapeshellarg` 处理后代入）。
3. 解析规则与 v1 一致：`Duration/start/bitrate`、`Video`、`Audio` 三段正则，`seconds` 由 `hh:mm:ss` 换算，`play_time = seconds + start`，`size` 取文件大小。
4. 文件不存在、命令无法执行或输出为空时抛 `RuntimeException` / `InvalidArgumentException`，不返回半截数据。
5. 补测试：用 PHP 自身输出固定文本模拟探测命令，断言全部字段与错误分支。
6. 更新对等快照与 `docs/file.md`。

## 影响范围

`src/File/VideoInfo.php`（新增）、对应测试、`docs/file.md`、`tests/Parity/legacy-api.json`；不改 `MediaInfo`。

## 验证方式

1. 模拟命令可解析出 v1 的全部字段。
2. 文件不存在与命令失败有明确异常。
3. `pnpm verify` 全绿。

## 回滚方案

新增类可整体回退；不触碰既有文件能力。
