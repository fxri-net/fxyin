# 实现 Http 层

> 计划位置：第 4/8 项（批次 B4）　前置：第 2 项

## 背景

旧 `app/controller/facade/Client.php`、`Server.php` 存在三类问题：一是大小写、来源等行为用 `$type` 数字码选择；二是 `ip()` 无条件信任 `HTTP_X_FORWARDED_FOR`，可被伪造；三是 `browser()` 用 `strpos` 返回位置做真值判断，命中首位时误判。响应侧 `Server::format()` 靠 `server.echo.template` 与 `server.echo.format` 两段数字键配置把位置数组重命名成键名，字段含义完全由配置位置决定。

本任务把请求上下文、响应输出、Cookie 与 HTTP 客户端重写为具名枚举与结构化对象。

## 实施方案

1. `src/Http/RequestContext`、`src/Http/ServerContext`：从 PSR-7 请求或超全局变量构造，方法显式返回类型，不再直接读超全局。
2. `src/Http/ClientInfo`：`ip()` 默认取 `IpSource::Remote`，`IpSource::Forwarded` 必须显式启用并配置可信代理网段；`system()` / `browser()` 的大小写改 `CaseFormat{Original, Lower, Upper}`，UA 判定改 `str_starts_with` / `str_contains`，消除首位误判。
3. `src/Http/Responder`、`src/Http/Envelope`、`src/Http/Formatter`：`Envelope` 固定字段 `ok`、`code`、`message`、`data`；`Formatter` 为接口，默认实现输出 JSON，替换格式化只需换实现，`server.echo.template` 与 `server.echo.format` 两段数字配置随之删除。
4. `src/Http/View`：视图渲染，接受渲染器实现，不内置模板引擎。
5. `src/Http/Cookie/CookieJar`：Cookie 读写与签名，替代全局静态 `Cookie`。
6. `src/Http/HttpClient/`：基于 PSR-18 的客户端与工厂，未安装实现包时抛明确异常，不静默降级。

## 影响范围

新增 `src/Http/` 全层与对应测试。不改 `frame/Cookie.php`、旧 `app/controller/facade/Client.php` 与 `Server.php`，第 8 项任务统一移除。

## 验证方式

- `tests/Http/ClientInfoTest.php` 断言默认不采信 `X-Forwarded-For`；仅在 `IpSource::Forwarded` 加可信代理时采信。
- 断言 `CaseFormat` 三个分支的输出，以及 UA 首位命中不再误判。
- `tests/Http/ResponderTest.php` 断言默认 JSON 结构与替换 `Formatter` 后的输出。
- `composer check` 零失败。
- 归档后跑 `toolkit tasks check`。
