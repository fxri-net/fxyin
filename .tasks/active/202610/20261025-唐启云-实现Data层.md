# 实现 Data 层

> 计划位置：第 6/8 项（批次 B6）　前置：第 5 项

## 背景

旧 `app/controller/facade/Data.php` 把两件事混在一起：数据比较、树形整理、字段表达式本应只返回数据，却用 `fxy_echo` 返回 HTTP 响应信封，`缺少新数据`、`数据格式错误`、`数据相同`、`检查成功` 等 9 处调用让纯函数带上输出副作用。字段方法又用 `$param` 数字码选择行为：`fieldJson` 的 1/2、`fieldText` 的 1/2/3、`fieldDate` 的 1/2/3、`paramEmpty` 的 1/2。

本任务在 Sql 层之上重写 Data，数字码换成具名枚举，失败路径改为抛异常。

## 实施方案

1. `src/Data/Diff`：数据差异比较，返回差异结构；无差异时抛 `SameDataException`，缺参时抛 `ValidationException`，不再返回响应信封。
2. `src/Data/Tree`：扁平列表与树形结构互转，支持自定义主键与父键。
3. `src/Data/Field`：字段表达式构造，依赖 `src/Sql/Dialect` 输出方言片段。`FieldJsonMode{Quoted, Raw}` 取代 `fieldJson` 的 `$param`；`FieldTextMode{Keep, ReplaceEmpty, CastInt}` 取代 `fieldText` 的 `$param`；`DateGranularity{DateTime, Date, Time}` 取代 `fieldDate` 的 `$param`。
4. `src/Data/Param`：参数规范化，`NullPolicy{Blank, StrictNull}` 取代 `paramEmpty` 的 `$type`。
5. `src/Data/Html`：HTML 片段生成与转义，纯字符串返回，无输出副作用。
6. `src/Exception/` 补齐本层所需异常类型，异常消息保持中文，标记 `#[\SensitiveParameter]` 的入参不得进消息。

## 影响范围

新增 `src/Data/`、`src/Exception/` 与对应测试。旧 `app/controller/facade/Data.php` 与 `Text.php` 中的 `fxy_echo` 调用本任务不逐个改，随第 8 项任务整体移除。

## 验证方式

- `tests/Data/DiffTest.php` 断言相同数据抛 `SameDataException`、缺参抛 `ValidationException`，且不产生任何输出。
- `tests/Data/FieldTest.php` 用数据提供者覆盖 `FieldJsonMode`、`FieldTextMode`、`DateGranularity`、`NullPolicy` 全部取值，断言生成的 SQL 与绑定分离。
- `tests/Data/TreeTest.php` 断言树形往返一致。
- `composer check` 零失败。
- 归档后跑 `toolkit tasks check`。
