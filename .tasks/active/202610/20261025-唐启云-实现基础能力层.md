# 实现基础能力层

> 计划位置：第 2/8 项（批次 B2）　前置：第 1 项

## 背景

旧实现里文本、参数、文件三块工具全部以「数字开关 + 全局函数」形态存在：`Param::define` 用 14 个点分模式号（`1.1.1` 至 `2.2.2`）选择合并策略，`Text::uuid` 用 `$mode` 加 `$style` 两组数字码，`Math::rand` 用数字类型码，`fxy_echo` 混在纯数据方法里。调用方无法从签名读出语义，静态分析也无从约束。

本任务把这三块重写为带命名空间与显式类型的类，全部数字开关换成具名枚举或语义方法名。

## 实施方案

1. `src/Support/`：`Type`（类型判定与转换）、`Random`（`RandomCharset` 枚举取 `Numeric` / `Lower` / `Upper` / `Alnum`，并改用 `random_int`）、`Formatter`（数值与容量格式化）、`Dump`（调试输出，不写 stdout 之外的副作用）。
2. `src/Text/`：`Str`（长度改为 `?int $start = null, ?int $end = null`，`null` 表示不限）、`Encode`（base64 / url / html 编解码）、`Uuid`（`UuidMode{Standard, Upper32, Md5Upper}` 加 `UuidStyle{Upper32, Lower32, Upper16, Lower16}`，随机源改 `random_bytes`）、`Time`（时间戳与格式化，`DateGranularity{DateTime, Date, Time}` 供 Data 层复用）、`Ip`（IPv4 / IPv6 与整数互转）。
3. `src/Param/`：`Shape` 组合器，以 `Shape::merge()` / `Shape::only()` 两个静态入口，配合 `fillWhenAbsent()`、`fillWhenBlank()`、`nullWhenAbsent()`、`nullWhenBlank()`、`defaultsFirst()`、`json()`、`csv()` 表达旧 14 个模式号的语义；`Pipeline`、`Definition`、`Picker`、`Merger`、`Url`、`Json` 按其职责拆分，替代旧 `Param` 门面的巨型方法体。
4. `src/File/`：`Filesystem`（读写、原子写、目录遍历）、`Path`（拼接与规范化，取代三级 `dirname` 上推）、`MediaInfo`（MIME 与扩展名判定）。
5. 统一约束：全部文件 `declare(strict_types=1)`；公共方法显式参数与返回类型；不引入全局函数；不调用 `exit()`；不读写全局静态状态。

## 影响范围

新增 `src/Support/`、`src/Text/`、`src/Param/`、`src/File/` 与对应 `tests/` 用例。不修改旧 `app/controller/facade/` 下的实现，旧代码在第 8 项任务统一移除。

## 验证方式

- `tests/Param/ShapeTest.php` 用数据提供者逐一覆盖旧 14 个模式号到新组合的映射，保证行为等价。
- `tests/Text/UuidTest.php` 断言四种 `UuidStyle` 的字符集、长度与大小写。
- `composer check` 零失败，且 `tools/no-numeric-code.php` 对新增目录无告警。
- 归档后跑 `toolkit tasks check`。
