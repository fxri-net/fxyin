# 补齐 1.x 升级 2.0 指南

延续「补全文档站内容」（见 archive/202610/20261025.md）；该轮已建立文档站与 2.0 迁移说明，本次补齐面向 1.x 使用者的可执行升级方案。

计划位置：本轮第 2 项；前置：版本标签与日志收口。

## 背景

- 现有 `docs/migration-2.0.md` 是 API 对照表，缺少升级前置、路线选择、分阶段步骤、扩展目录迁移与回滚。
- 本机 Dev-Space 下 13 个接入方仓库均为 `extend/fxri/base` + `extend/fxri/data` 的解压接入方式，形态覆盖 ThinkPHP 6、ThinkPHP 5、非 ThinkPHP 与无 Composer 四类。
- 这些仓库的旧 API 调用、六元响应下标、点分模式号集中在业务层与扩展目录，单靠类名对照无法完成升级。
- `safe` / `safe_local` 是独立工具，不属于 fxyin 迁移范围，指南只做边界声明。

## 实施方案

新增与改造 5 篇文档：

1. `docs/upgrade-2.0.md`：版本策略与 1.x EOL、升级前置、项目自评表、决策树、S/M/L 三条路线、阶段划分、回滚、子文档索引。
2. `docs/upgrade-2.0-runtime.md`：ThinkPHP 6、ThinkPHP 5、非 ThinkPHP、无 Composer 四类接入模板；根 `index.php` 与 `public/index.php`、`bootstrap.php` 与直接 include 的入口变体；`KernelBuilder` 装配与容器绑定。
3. `docs/upgrade-2.0-extend.md`：`extend/fxri/base` 与 `extend/fxri/data` 的逐项对照；配置纯度规则；`facade_ext`、`oracle`、`store` 钩子的替代方式；删除顺序。
4. `docs/migration-2.0.md`：保留原文件名，改为「2.0 API 对照」，补分域索引、高频 API、无等价能力与行为差异。
5. `docs/upgrade-2.0-checklist.md`：阶段 0–7 的 S/M/L 清单、基线模板、常见卡点与回滚清单。

同步更新导航与入口：`docs/.vitepress/config.mts` 增加「升级」分组，`README.md`、`docs/index.md`、`docs/getting-started.md` 增加升级入口，`docs/faq.md` 修正门面名称错误并补升级问答，`docs/contributing.md` 补标签规则。

文档示例一律使用「接入方 A/B/C」与占位路径，不写真实仓库名、数据库名、密钥或服务器地址。

## 影响范围

`docs/` 下新增 4 篇、改造 1 篇，`docs/.vitepress/config.mts`、`README.md`、`docs/index.md`、`docs/getting-started.md`、`docs/faq.md`、`docs/contributing.md`；不改 `src/`，不改任何接入方仓库。

## 验证方式

1. `pnpm docs:build` 通过，站内链接零死链。
2. 5 篇文档互相可达，导航与侧栏均出现入口。
3. 全文检索确认无真实仓库名、内网地址、密钥与 `branch.php` 内容。
4. `pnpm verify` 全绿。

## 回滚方案

文档与导航均为普通提交，`git revert` 即恢复；不影响 2.x 运行时与接入方仓库。
