# 收口文档美化与 README 瘦身

> 计划位置：第 6/6 项（批次 B6）　前置：第 2、4、5 项

## 背景

文档站建成后，README 仍堆着装配项表、能力划分表与接入示例，与站点内容重复；各页排版与术语也需统一。

## 实施方案

1. README 瘦身为导航页：定位一句话、运行环境要求、安装命令、最小装配示例、文档站入口（快速开始 / 能力参考 / 迁移指南 / 更新日志）、版权信息；装配项表、能力划分表、接入示例等技术细节全部由站点承载，README 只留链接。
2. README 加状态徽章：流水线状态、PHP 版本、许可证、文档站。
3. 各文档页统一排版：标题层级、示例代码块语言标注、表格紧凑形态、术语与类名写法一致。
4. 首页与站点主题细节收口：能力卡片文案、页脚、社交链接。
5. 全站链接核对：README → 站点、站点内部互链、迁移指南对 `src/` 的引用。
6. 生成 `docs/changelog.md` 镜像，确认与根 `CHANGELOG.md` 一致。

## 影响范围

改 `README.md` 与各文档页排版；不改源码与依赖。

## 验证方式

- README 不再出现逐项装配表与能力清单，链接可达站点对应页。
- `pnpm docs:build` 零死链。
- 徽章地址与实际仓库路径一致。
- 归档后跑 `toolkit tasks check`。
