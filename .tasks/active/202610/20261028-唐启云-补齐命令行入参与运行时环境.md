# 补齐命令行入参与运行时环境

延续「补齐请求入参与递归文件列表」（见 active/202610/20261028-唐启云-补齐请求入参与递归文件列表.md）。v1.6.1 由 `app/store/common.php` 依次执行 `Param::init()`、`Env::init()`、`Server::env()`，v2 尚缺对应入口。

计划位置：本轮第 2 项；前置：补齐请求入参与递归文件列表。

## 背景

- `Param::init()` 解析 `argv` 中以 `@` 开头的 `@a.b=值` 参数，构建嵌套数组、注入配置 `app.param.cli`，并从 `argv` 移除已消费项。v2 没有命令行解析。
- `fxyin\Env` 是运行期环境叠加层，`init/load/has/get/set` 均为运行期读写；v2 矩阵误指向 `.env` 文本解析器 `Config\Environment`，实际应由 `Config\Store` 与 `File\Loader` 承接。
- `Server::env()` 在 CLI 下用配置 `app.param.cli.svr_name` / `svr_uri` 兜底 `SERVER_NAME` 与 `REQUEST_URI`。v2 `ServerContext` 只做快照，没有兜底入口。

## 实施方案

1. 新增 `Application\Cli`：`parse(array $argv)` 返回「剩余参数 + 嵌套值」，`fromGlobals()` 读 `$_SERVER['argv']`，`serverDefaults(Config|Store)` 从配置取 CLI 主机与路径。
2. `Bootstrap::withCliArguments()` 显式开启命令行解析；启动时把解析结果写入内核 `configStore()` 的 `app.param.cli`，并把主机、路径写入 `env.base.host` / `env.base.uri`。
3. `ServerContext::fromGlobals(array $defaults = [])` 与 `RequestContext::fromGlobals(array $defaults = [])` 接受兜底值，真实变量优先。
4. `Env` 能力以 `Config\Store` 为写入层、`File\Loader::read()` 为文件入口：`Env::load($file, $name)` 等价于 `$store->set('env.' . $name, Loader::read($file))`；不新增中间类。
5. 补测试：`@` 参数解析、嵌套键与 `/_` 还原、参数移除、配置注入、CLI 主机与路径兜底、`env` 命名空间叠加。
6. 更新对等快照与文档：`Param::init` → `Application\Cli`，`Env::*` → `Config\Store` + `File\Loader`，`Server::env` → `Application\Cli` / `RequestContext::fromGlobals()`。

## 影响范围

`src/Application/Cli.php`（新增）、`src/Application/Bootstrap.php`、`src/Http/ServerContext.php`、`src/Http/RequestContext.php`、对应测试、`docs/application.md`、`docs/http.md`、`docs/config.md`、`docs/parity-1.6.1.md`、`tests/Parity/legacy-api.json`；默认不解析命令行，未开启时行为不变。

## 验证方式

1. 未调用 `withCliArguments()` 时启动结果与当前一致。
2. 开启后 `app.param.cli` 与 `env.base.*` 可按预期读取。
3. `pnpm verify` 全绿；对等审计计数不变。

## 回滚方案

命令行解析为显式开启的可选能力，回退提交即恢复；`fromGlobals()` 新增参数可省略，向后兼容。
