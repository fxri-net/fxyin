# 搭建文档站骨架

> 计划位置：第 3/6 项（批次 B3）　前置：第 1 项

## 背景

现状 `docs/` 只有一份 2.0 迁移指南，没有站点、导航与检索，README 因此被迫承载大量技术细节。本任务把文档站立起来，让 README 退回导航页。

## 实施方案

1. `docs/.vitepress/config.mts`：`base` / `siteUrl` / `repo` 由环境变量注入（本地默认 `/`）；中文语言、标题模板、最后更新时间、sitemap、Open Graph 与 favicon 头；导航分「指南 / 参考 / 答疑」三组，侧栏按能力层分组；本地搜索启用中文文案；页脚、编辑链接、上一篇/下一篇与返回顶部中文化。
2. `docs/public/`：站点标识与社交分享图，用图像生成接口产出，不使用占位图。
3. `docs/index.md`：首屏主视觉（名称、一句话定位、快速开始与迁移指南两个入口）+ 能力卡片。
4. `docs/getting-started.md`：安装、装配、最小可运行示例、目录约定。
5. `docs/migration-2.0.md`：由仓库根 `docs/migration-2.0.md` 原路径就地保留并纳入站点，补齐 frontmatter 与站内链接。
6. `scripts/sync-changelog-doc.mjs`：把根 `CHANGELOG.md` 全量镜像到 `docs/changelog.md`，固定页头、只列版本级目录、剥离源标题并校验版本块存在。
7. 站点构建通过：死链检测零报错。

## 影响范围

新增文档站配置、素材与三篇入口文档；`docs/migration-2.0.md` 增加 frontmatter 与站内链接；根 `CHANGELOG.md` 多一份镜像页。不改源码。

## 验证方式

- `pnpm docs:build` 产出 `docs/.vitepress/dist/index.html`、`sitemap.xml`、`404.html`，无死链告警。
- 首页、快速开始、迁移指南、更新日志四页可导航互达。
- `docs/changelog.md` 与根 `CHANGELOG.md` 版本段一致。
- 归档后跑 `toolkit tasks check`。
