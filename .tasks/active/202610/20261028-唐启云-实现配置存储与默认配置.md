# 实现配置存储与默认配置

对等计划第 3 项；前置：能力矩阵。

## 背景

v1.6.1 的 `Config` 支持运行期 `set`，v2 只有只读 `Config`；同时默认配置尚未随包提供。

## 实施方案

1. 新增 `Config\Store`：`get/has/set/all`，以只读 `Config` 为基底，运行期覆盖独立存放。
2. `Kernel` 暴露 `config()`（只读）与 `configStore()`（可写覆盖），保持内核不可变。
3. `Config\Loader` 先加载 `resources/config`，再按 `withConfigDir()` 顺序叠加项目配置。
4. 默认配置值与 v1.6.1 对齐；`facade` 等 1.x 专用配置不进入默认资源。
5. 补测试：读取、覆盖、运行期写入、默认值与项目覆盖顺序。

## 影响范围

`src/Config/**`、`src/Kernel.php`、`src/KernelBuilder.php`、测试与文档。

## 验证方式

1. 默认值对比一致；项目配置覆盖顺序一致。
2. `configStore()->set()` 后读取生效，`config()` 仍只读。
3. `pnpm verify` 通过。

## 回滚方案

`Config\Store` 为新增能力，回退提交即恢复；默认配置可用开关关闭。
