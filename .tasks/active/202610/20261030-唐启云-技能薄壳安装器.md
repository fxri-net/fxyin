# 技能薄壳安装器

批次：单批　计划位置：本轮第 3 项　前置：技能版本与许可证

## 一、背景

技能真源随 Composer 包进入 `vendor/fxri/fxyin/skills/`，但 agent 不会扫描 vendor。项目面只需入口薄壳指向真源，不应复制一份、也不应写入全局目录。

## 二、实施方案

1. 新增 `src/Tooling/SkillInstaller.php`：
   - `install(string $projectRoot, array $targets = ['.agents/skills']): array`：读取 `skills/*/SKILL.md` 的 frontmatter，生成同名薄壳（含 name、description、`<!-- fxyin-skill-entry: v1 -->` 与真源相对路径）；
   - `check(string $projectRoot, array $targets = ['.agents/skills']): bool`：校验薄壳存在且指向当前真源；
   - 幂等：重复安装覆盖本包生成内容，不碰同名非本包产物。
2. 新增 `tools/install-skills.php`：项目侧入口，支持 `--target`（可多次）、`--check`、`--root`。
3. `docs/` 增加一节说明（`docs/ide.md` 或新建 `docs/skills.md`），写清「薄壳指向 vendor、不复制、不写全局、Trae 用 `--target .trae/skills`」。
4. 新增 `tests/Tooling/SkillInstallerTest.php`：薄壳内容、幂等、`check` 命中与不一致、非法目标目录。

## 三、影响范围

- 新增工具类与命令，不改运行代码；文档新增一页或一节并接入导航。

## 四、验证方式

1. 单测覆盖安装与校验。
2. 在本仓运行 `php tools/install-skills.php --check` 前先安装到临时目录验证，不污染仓库。
3. `pnpm verify` 通过。

## 五、回滚

单次提交，可整体 `git revert`。
