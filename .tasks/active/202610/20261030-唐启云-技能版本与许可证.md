# 技能版本与许可证

批次：单批　计划位置：本轮第 2 项　前置：三方一致规范

## 一、背景

两个技能只有 frontmatter 版本，缺正文版本行，不满足「版本写两处且一致」；同时 `license: MIT` 与本仓 Apache-2.0 不一致。

## 二、实施方案

1. 两个 `SKILL.md` 正文首部各加一行：`> 本技能版本 1.0.1（随 fxri/fxyin 同批分发）`。
2. frontmatter `metadata.version` 同步为 `1.0.1`。
3. frontmatter `license` 改为 `Apache-2.0`。
4. references 无需内容变更。

## 三、影响范围

- 仅技能文件；不影响运行与构建。`docs/` 无触达页面。

## 四、验证方式

1. 两处版本字符串一致，frontmatter 可解析。
2. `pnpm verify` 通过。

## 五、回滚

单次提交，可整体 `git revert`。
