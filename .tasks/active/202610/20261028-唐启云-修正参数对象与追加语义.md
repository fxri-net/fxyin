# 修正参数对象与追加语义

延续「补齐旧令牌与旧密文兼容」（见 active/202610/20261028-唐启云-补齐旧令牌与旧密文兼容.md）。复核 `Param` 后发现两处映射只在名义上成立。

计划位置：本轮第 5 项；前置：补齐旧令牌与旧密文兼容。

## 背景

- v1 `Param::object()` 只把空数组转成 `stdClass`，非空数组保持数组；v2 `Data\Cast::toObject()` 把所有数组都转对象，列表会编码成 `{"0":…}`。
- v1 `Param::append(...$args)` 是数组追加：字符串键覆盖、数字键追加；v2 矩阵指向 `Param\Pipeline`，而定形流水线与追加无关。

## 实施方案

1. `Data\Cast` 新增 `emptyToObject(mixed $value, int $limit = -1)`：只把空数组转 `stdClass`，非空数组递归处理但保持数组，与 v1 语义一致；现有 `toObject()` 保持 v2 语义。
2. `Param\Merger` 新增 `append(array ...$arrays)`：字符串键覆盖、数字键追加，与 v1 `Param::append()` 一致。
3. 对等快照把 `Param.object` 指向 `Cast::emptyToObject`，`Param.append` 指向 `Merger::append`。
4. 补测试：空数组与非空数组/列表的对象化差异、追加的键与顺序。
5. 更新 `docs/data.md`、`docs/param.md` 的相关说明。

## 影响范围

`src/Data/Cast.php`、`src/Param/Merger.php`、对应测试、文档、`tests/Parity/legacy-api.json`；不改 `toObject()` 与 `merge()` 现有行为。

## 验证方式

1. 新增用例覆盖两种对象化语义与追加规则。
2. 既有 `Cast`、`Merger` 测试保持通过。
3. `pnpm verify` 全绿。

## 回滚方案

新增方法可整体回退；既有方法与映射不变。
