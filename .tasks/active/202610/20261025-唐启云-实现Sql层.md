# 实现 Sql 层

> 计划位置：第 5/8 项（批次 B5）　前置：第 2 项

## 背景

旧 `app/config/facade.php` 用 `data.where` 一段八槽位数字键描述 SQL 片段参数：`-1` 表达式、`0` 键名、`1` 键值、`2` 方法、`3` 逻辑、`4` 分组、`5` 取反、`6` 大小写。调用方按位置数组传参，读代码必须回查配置才知道第几位是什么。值直接拼进 SQL 字符串，`ifnull`、`find_in_set`、`json_contains` 等方言函数散落在门面方法里，存在注入面。

本任务建立独立的 SQL 构建层，用值对象与枚举取代位置槽位，值一律走绑定参数。

## 实施方案

1. `src/Sql/Sql`：结果值对象，只含 `sql` 字符串与 `bindings` 数组，两者分离，禁止把值拼进字符串。
2. `src/Sql/Expression`：原生表达式值对象，构造时即标注为不可绑定片段，调用方无法误传裸字符串。
3. `src/Sql/WhereOperator`：枚举 `Eq`、`Ne`、`Gt`、`Gte`、`Lt`、`Lte`、`Like`、`In`、`NotNull`、`Null`、`Between`，替代数字槽位 `2` 方法位。
4. `src/Sql/Boolean`：`And`、`Or`，替代逻辑位；`src/Sql/Collation`：`CaseSensitive`、`CaseInsensitive`，替代大小写位。
5. `src/Sql/WhereBuilder`：链式 API，`eq()`、`gte()`、`in()`、`not()`、`nested(Closure)`、`group()` 覆盖原分组位与取反位；`src/Sql/StatementBuilder`：生成 SELECT / INSERT / UPDATE / DELETE 骨架。
6. `src/Sql/Dialect/DialectInterface` 与 `src/Sql/Dialect/MysqlDialect`：方言差异全部收敛在实现里，`ifnull`、`find_in_set`、`json_contains`、`from_unixtime` 等由方言方法输出，不在业务层出现。
7. 删除 `data.where` 配置段，语义全部由上述枚举与方法签名承载。

## 影响范围

新增 `src/Sql/` 全层与对应测试。旧 `app/controller/facade/Data.php` 的拼接方法本任务不改，第 6 项任务在其上层重写，`data.where` 配置段在第 8 项任务随旧配置一并删除。

## 验证方式

- `tests/Sql/WhereBuilderTest.php` 断言每个 `WhereOperator` 生成的 SQL 片段与绑定数组。
- 注入用例：值取 `' OR 1=1 -- ` 时，该串必须出现在绑定数组且不出现在 `Sql::sql` 中。
- `tests/Sql/Dialect/MysqlDialectTest.php` 断言各方言函数的输出形态。
- `composer check` 零失败。
- 归档后跑 `toolkit tasks check`。
