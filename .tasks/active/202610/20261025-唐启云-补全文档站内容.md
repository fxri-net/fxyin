# 补全文档站内容

> 计划位置：第 4/6 项（批次 B4）　前置：第 3 项

## 背景

站点骨架就位后，需要把 `src/` 各能力层写成使用者能查的参考页，否则 README 仍是唯一信息来源。

## 实施方案

按 `src/` 分层各写一篇，均含定位、最小示例、参数与返回值、注意事项：

1. `kernel.md`：`Kernel`、`KernelBuilder`、`Package`。
2. `param.md`：`Param`、`Definition`、`Shape`、`Pipeline`、`Merger`、`Picker`、`Json`、`Url` 与 `BaseMode`、`TriggerMode`、`FillMode`、`TransformMode` 四个枚举。
3. `data.md`：`Field`、`FieldJsonMode`、`FieldTextMode`、`Tree`、`Diff`、`Html`、`NullPolicy`。
4. `sql.md`：`Sql`、`Expression`、`WhereBuilder`、`StatementBuilder`、`WhereOperator`、`Boolean`、`Collation`、方言接口与 MySQL 方言。
5. `text.md`：`Str`、`Encode`、`Ip`、`Time`、`DateGranularity`、`Uuid`、`UuidMode`、`UuidStyle`。
6. `file.md`：`Filesystem`、`Path`、`MediaInfo`。
7. `security.md`：`Cipher`、`Hash`、`HashLength`、`Rsa`、`Token`、`LegacyCipher`。
8. `http.md`：`Envelope`、`Formatter`、`JsonFormatter`、`Renderer`、`Responder`、`RequestContext`、`ServerContext`、`ClientInfo`、`View`、`CaseFormat`、`IpSource`、Cookie 三件套、HTTP 客户端两件。
9. `config.md`：`Config`、`ConfigLoader`、`Environment`、`ArrayTranslator`、`PhpFileLoader`。
10. `support.md`：`Dump`、`Formatter`、`Random`、`RandomCharset`、`Type`。
11. `integration.md`：ThinkPHP 容器绑定与异常映射。
12. `contributing.md`：开发环境、验收命令、提交规范、任务流程；发版链路按全局 `toolkit changelog` 写全 —— 建变更集用 `toolkit changelog`（不装本地 `@changesets/cli`）、消费发版用 `toolkit changelog version`、人工润色后 `toolkit changelog --history format` 归一、`pnpm verify`、提交、打 `vX.Y.Z` 标签并推送（需维护者确认）；并注明该命令会连带扫描改写 `vendor/**/CHANGELOG.md`（`vendor` 可再生产物，不入库）。
13. `faq.md`：常见装配与迁移疑问。

示例必须与 `src/` 实际签名一致（构造可见性、返回类型、必填参数），不写未实现的用法。

## 影响范围

只新增文档页与导航/侧栏条目；不改源码。

## 验证方式

- `pnpm docs:build` 零死链。
- 每篇示例的类名与方法名在 `src/` 中存在且签名一致。
- 导航与侧栏无空链、无重复分组。
- 归档后跑 `toolkit tasks check`。
