# AI 技能包

批次：单批　计划位置：本轮第 3 项　前置：元数据生成器

## 一、背景

框架能力与工具逐渐增多（配置递归、泛型、`upgrade-inspect`、`MetaGenerator`），人工心智负担上升，AI 也缺少稳定的入口与路由。需要一套与具体项目无关的通用技能包。

## 二、实施方案

拆成两个技能，统一 `fxri-` 前缀：

1. `skills/fxri-fxyin/`（日常接入与使用）：
   - `SKILL.md`：触发条件、决策树、常用命令、边界声明；
   - `references/{setup,response,config,ide,api}.md`：装配、五键响应与分页、配置递归、IDE 元数据、常用 API 速查。
2. `skills/fxri-fxyin-upgrade/`（1.x → 2.x 迁移）：
   - `SKILL.md`：迁移阶段与验收；
   - `references/{stages,mapping,inspect}.md`：阶段步骤、门面与参数映射、`profile/scan/baseline` 用法。

边界：

- 两个技能都不写具体业务仓名与项目命名决策；项目决策以项目 `.tasks` 为准。
- 不复制 `docs/` 正文，只做路由与关键结论。
- 升级技能不重复响应与配置细节，指回日常技能与文档。

## 三、影响范围

- 仅新增技能文件，不影响运行与依赖。

## 四、验证方式

1. 技能文件结构完整，`SKILL.md` 描述可触发。
2. `pnpm verify` 不受影响（技能目录不参与构建）。

## 五、回滚

单次提交，可整体 `git revert`。
